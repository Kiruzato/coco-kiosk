================================================================================
CoCo Campus Kiosk - Windows Setup Instructions
================================================================================

This guide explains how to set up and run the CoCo campus information kiosk
on a Windows development machine.

================================================================================
PREREQUISITES
================================================================================

Required:
---------
1. Python 3.11 (recommended) or Python 3.8+
   Download from: https://www.python.org/downloads/
   - During installation, check "Add Python to PATH"
   - Check "Install py launcher"

2. Git (for cloning the repository)
   Download from: https://git-scm.com/download/win

3. OpenAI API Key
   Get from: https://platform.openai.com/api-keys

Optional (for full voice functionality):
----------------------------------------
4. FFmpeg (for audio format conversion)
   Download from: https://ffmpeg.org/download.html
   - Extract to a folder (e.g., C:\ffmpeg)
   - Add C:\ffmpeg\bin to your system PATH

5. Poppler (for layout-aware PDF parsing)
   Download from: https://github.com/osber/poppler-for-windows/releases
   - Without this, PDFs will use basic parsing (still works)


================================================================================
QUICK START (Automated Setup)
================================================================================

1. Open PowerShell as Administrator

2. Navigate to the project folder:
   cd C:\path\to\vibecoding_coco

3. Allow script execution (if not already enabled):
   Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

4. Run the setup script:
   .\win-setup.ps1

5. Follow the prompts to:
   - Create virtual environment
   - Install dependencies
   - Configure your .env file with API keys
   - Ingest documents

6. Start the server:
   .\venv\Scripts\Activate.ps1
   cd campus_rag_chatbot
   python app.py

7. Access the kiosk at:
   http://localhost:8000/


================================================================================
MANUAL SETUP (Step-by-Step)
================================================================================

If you prefer manual setup or the script fails:

Step 1: Clone the repository
----------------------------
git clone https://github.com/Kiruzato/coco-kiosk.git
cd coco-kiosk
git checkout antigravity-dev-2

Step 2: Create virtual environment
----------------------------------
py -3.11 -m venv venv
.\venv\Scripts\Activate.ps1

Step 3: Install dependencies
----------------------------
pip install --upgrade pip
pip install -r campus_rag_chatbot\requirements.txt

Step 4: Configure environment
-----------------------------
copy campus_rag_chatbot\.env.example campus_rag_chatbot\.env
notepad campus_rag_chatbot\.env

Add your API keys:
  OPENAI_API_KEY=sk-your-key-here
  ADMIN_API_KEY=any-random-uuid-here

Step 5: Ingest documents
------------------------
cd campus_rag_chatbot
python admin.py ingest documents_to_ingest/

Step 6: Start the server
------------------------
python app.py


================================================================================
STARTING THE APP (After Initial Setup)
================================================================================

Each time you want to run the app:

1. Open PowerShell
2. Navigate to the project:
   cd C:\path\to\vibecoding_coco

3. Activate virtual environment:
   .\venv\Scripts\Activate.ps1

4. Start the server:
   cd campus_rag_chatbot
   python app.py

5. Open browser to:
   http://localhost:8000/

To stop the server: Press Ctrl+C in PowerShell


================================================================================
ACCESS POINTS
================================================================================

After starting the server:

- User Interface:    http://localhost:8000/
- Admin Interface:   http://localhost:8000/admin
- Developer Tools:   http://localhost:8000/dev
- Voice Status:      http://localhost:8000/voice/status
- Health Check:      http://localhost:8000/health


================================================================================
COMMON ISSUES AND SOLUTIONS
================================================================================

Issue: "execution of scripts is disabled on this system"
---------------------------------------------------------
Solution: Run PowerShell as Administrator and execute:
  Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser


Issue: Python not found
-----------------------
Solution: Ensure Python is installed and added to PATH
  - Reinstall Python with "Add to PATH" checked
  - Or use full path: C:\Python311\python.exe


Issue: pip install fails with "Microsoft Visual C++ required"
--------------------------------------------------------------
Solution: Install Visual Studio Build Tools
  Download from: https://visualstudio.microsoft.com/visual-cpp-build-tools/
  Select "Desktop development with C++"


Issue: Piper TTS not working / Voice errors
-------------------------------------------
This is expected on Windows. The system will automatically fall back to
Edge-TTS (cloud-based) for text-to-speech. Edge-TTS provides high-quality
voice output and requires internet connection.


Issue: PDF parsing errors
-------------------------
Layout-aware PDF parsing requires poppler. Without it, the system uses
basic PDF parsing which still works for most documents.

To install poppler:
1. Download from https://github.com/osber/poppler-for-windows/releases
2. Extract to C:\poppler
3. Add C:\poppler\bin to system PATH
4. Restart PowerShell


Issue: "libmagic" or "magic" errors
-----------------------------------
Solution: The setup script installs python-magic-bin automatically.
If you see this error, run:
  pip install python-magic-bin


Issue: Audio/voice features not working
---------------------------------------
Ensure FFmpeg is installed and in PATH:
1. Download from https://ffmpeg.org/download.html
2. Extract to C:\ffmpeg
3. Add C:\ffmpeg\bin to system PATH
4. Restart PowerShell
5. Verify: ffmpeg -version


================================================================================
DIFFERENCES FROM RASPBERRY PI DEPLOYMENT
================================================================================

This Windows setup is for development/testing purposes. Key differences:

| Feature              | Raspberry Pi          | Windows               |
|----------------------|-----------------------|-----------------------|
| TTS Engine           | Piper (offline)       | Edge-TTS (cloud)      |
| STT Engine           | Whisper.cpp (offline) | Whisper.cpp or cloud  |
| PDF Parsing          | Full layout-aware     | Basic (without poppler)|
| Kiosk Mode           | Fullscreen optimized  | Windowed browser      |
| Auto-start           | systemd service       | Manual start          |

The core RAG functionality, chat interface, and admin features work
identically on both platforms.


================================================================================
TROUBLESHOOTING COMMANDS
================================================================================

Check Python version:
  python --version
  py -3.11 --version

Check installed packages:
  pip list

Check if virtual environment is active:
  (venv) should appear in your prompt

Reinstall all dependencies:
  pip install --force-reinstall -r campus_rag_chatbot\requirements.txt

Clear vector store and re-ingest:
  Remove-Item -Recurse campus_rag_chatbot\vector_store
  python admin.py ingest documents_to_ingest/
