================================================================================
FIX REPORT: Truncated Chatbot Responses
================================================================================
Date: 2026-01-27
Project: CoCo - Campus RAG Chatbot
Phase: 17B.1 Hotfix

================================================================================
1. PROBLEM DESCRIPTION
================================================================================

Two user queries were producing broken/truncated responses:

Query 1: "what is the lyrics of columban hymn"
- Expected: Full hymn lyrics (multiple verses)
- Actual: Only first verse displayed
  "The lyrics of the Columban Hymn are as follows: Step together, brave and
  free Family of Columban We know that we can lead the way In the land we
  love today."

Query 2: "List the deans of this school"
- Expected: Complete list of all deans
- Actual: Response cut off mid-sentence
  "The deans of Columban College, Inc. are Dr."

================================================================================
2. ROOT CAUSE ANALYSIS
================================================================================

The truncation was introduced in Phase 17B.1 (Structured Response Objects)
through three interconnected issues:

Issue 1: Answer Overwrite (app.py line 1036)
--------------------------------------------------------------------------
The code was replacing the full LLM answer with a truncated "direct_answer":

    # Keep plain answer as direct_answer for backward compatibility
    answer = structured_data.get("direct_answer", answer)

This line overwrote the complete response with only 1-2 sentences.

Issue 2: Intentional Truncation in Response Formatter (response_formatter.py)
--------------------------------------------------------------------------
The extract_direct_answer() function was designed to extract only the first
1-2 sentences:

    def extract_direct_answer(raw_answer: str) -> str:
        sentences = extract_sentences(raw_answer)
        direct = sentences[0]
        if len(sentences) > 1 and len(direct) < 80:
            direct = f"{sentences[0]} {sentences[1]}"
        return direct

Additionally:
- key_details limited to 5 items: return details[:5]
- notes limited to 3 items: return notes[:3]

Issue 3: Frontend Only Showed Structured Answer (app.js)
--------------------------------------------------------------------------
When structured_answer existed, the frontend only rendered the truncated
structured version, never the full answer:

    if (data.structured_answer) {
        html += renderStructuredAnswer(data.structured_answer);
    } else {
        html += `<p class="large-text">${escapeHtml(data.answer)}</p>`;
    }

================================================================================
3. SOLUTION IMPLEMENTED
================================================================================

The fix preserves the structured answer format while adding a "Show full answer"
expandable section for longer responses.

Change 1: Added full_answer field to response formatter
--------------------------------------------------------------------------
File: campus_rag_chatbot/response_formatter.py
Location: build_structured_answer() return dict (line ~245)

Before:
    return {
        "direct_answer": direct_answer,
        "key_details": key_details,
        "notes": notes,
        "disclaimer": disclaimer
    }

After:
    return {
        "direct_answer": direct_answer,
        "full_answer": raw_answer,  # Preserve complete answer
        "key_details": key_details,
        "notes": notes,
        "disclaimer": disclaimer
    }

Change 2: Updated StructuredAnswer Pydantic model
--------------------------------------------------------------------------
File: campus_rag_chatbot/app.py
Location: class StructuredAnswer (line ~179)

Before:
    class StructuredAnswer(BaseModel):
        direct_answer: str
        key_details: List[str] = []
        notes: Optional[str] = None
        disclaimer: Optional[str] = None

After:
    class StructuredAnswer(BaseModel):
        direct_answer: str
        full_answer: str  # Complete answer for "Show more" expansion
        key_details: List[str] = []
        notes: Optional[str] = None
        disclaimer: Optional[str] = None

Change 3: Removed answer overwrite
--------------------------------------------------------------------------
File: campus_rag_chatbot/app.py
Location: handle_campus_query() (line ~1034-1037)

Before:
    if structured_data:
        structured_answer = StructuredAnswer(**structured_data)
        # Keep plain answer as direct_answer for backward compatibility
        answer = structured_data.get("direct_answer", answer)

After:
    if structured_data:
        structured_answer = StructuredAnswer(**structured_data)

Change 4: Fixed general query handler
--------------------------------------------------------------------------
File: campus_rag_chatbot/app.py
Location: handle_general_query() (line ~1102-1107)

Added full_answer field when creating StructuredAnswer manually:

    structured_answer = StructuredAnswer(
        direct_answer=structured_data["direct_answer"],
        full_answer=structured_data["full_answer"],  # Added
        key_details=structured_data["key_details"],
        notes=structured_data["notes"],
        disclaimer="[Based on general AI knowledge]"
    )

Change 5: Added expandable full answer section to frontend
--------------------------------------------------------------------------
File: campus_rag_chatbot/static/app.js
Location: renderStructuredAnswer() function (line ~61)

Added:
- Check if full_answer is significantly longer than direct_answer
- "Show full answer" button that toggles visibility
- Hidden container for full answer content
- toggleFullAnswer() function for expand/collapse behavior

Change 6: Added CSS styling for expand/collapse
--------------------------------------------------------------------------
File: campus_rag_chatbot/static/style.css
Location: End of Phase 17B.1 section

Added styles for:
- .full-answer-section container
- .show-more-btn button (with hover states)
- .full-answer-content expandable container
