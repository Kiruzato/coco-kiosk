Design and implement the Admin Directory Management System for CoCo.
The Campus Query Engine (CQE) and schema are already implemented.
Your task is to build a working Admin system that allows authorized administrators to manage campus data safely.
________________________________________
Scope
Build CRUD functionality for all entities in the current schema.
Ensure:
•	Entities can be created, edited, and deleted.
•	Relationships remain valid.
•	Required fields are enforced.
•	Invalid references are prevented.
•	Tags are normalized (lowercase, trimmed, no duplicates).
•	After any successful change, the CQE index is rebuilt.
Keep the system simple and clean.
________________________________________
Constraints
•	Use the current JSON persistence.
•	Do not redesign the schema.
•	Do not modify CQE logic unless strictly required for integration.
•	Do not add new architectural layers unless necessary.
•	Do not expand into intelligence features.
Focus only on making the Admin system functional, safe, and maintainable.
________________________________________
Deliverables
•	Admin architecture design
•	CRUD implementation plan
•	Validation logic
•	Safe index rebuild integration
•	Clear explanation of data flow
Avoid unnecessary abstractions.
Prioritize clarity, correctness, and simplicity.
