===============================================================================
ROOT CAUSE ANALYSIS
===============================================================================

PDF STRUCTURE CHALLENGE:
The source PDF (2022_student_manual_latest.pdf) has a scattered, non-
hierarchical structure:

- Page 12: "Deans" title section (1 element, NO content)
- Page 12: "DEANS" section in chunk 653 (ALL 6 deans, poor formatting)
- Pages 12-17: Multiple title-only sections (no content siblings)
- Pages 133-135: Additional dean references scattered

INITIAL APPROACH (FAILED):
Attempted layout-based section merging in merge_related_admin_sections():
- Logic: Merge title-only "Deans" section with following content
- Why it failed: Following sections were ALSO title-only
- Result: "Deans" title isolated, actual dean data in separate chunk 653

DISCOVERY:
ALL 6 deans exist in a SINGLE chunk (chunk 653, "DEANS" section, page 12), 
but with PDF parsing artifacts:

Chunk 653 content structure:
  Position ~60:  Almazan  (prefixed with "CHARPERSONS", whitespace artifacts)
  Position ~250: Capili   (text fragments, incomplete)
  Position ~340: Matriano (CLEAN FORMAT)
  Position ~390: Capili   (CLEAN FORMAT, 2nd occurrence)
  Position ~420: Yap      (CLEAN FORMAT)
  Position ~590: Gonzales (CLEAN FORMAT)
  Position ~650: Gutierrez (CLEAN FORMAT)

The 4 deans extracted have clean formatting.
The 2 missing deans have corrupted formatting from PDF parsing.

===============================================================================
SOLUTION: ENTITY-CENTRIC CONSOLIDATION
===============================================================================

APPROACH:
Pivoted from section-level merging to chunk-level entity consolidation.

IMPLEMENTATION:
Created entity_consolidation.py with consolidate_dean_chunks() function.

ALGORITHM:
1. Iterate through all document chunks
2. Semantic detection: Select chunks with BOTH "dean" AND person titles 
   (Dr., Engr., Arch., Prof., etc.)
3. Filter false positives:
   - Exclude chunks with "dean's office"
   - Exclude role description chunks ("Is tasked to assist...")
4. Consolidate identified chunks:
   - Sort by page number (ensures structured lists appear first)
   - Combine full chunk content (NOT line-by-line parsing)
   - Join with "---" separator
5. Create synthetic chunk:
   - Metadata: chunk_id=-1, is_synthetic=True, entity_type='deans'
   - Provenance: source_chunk_ids, page_numbers preserved
   - Content: "Deans\n\n" + consolidated content
6. Prepend synthetic chunk to documents list before vector store ingestion

INTEGRATION POINT:
document_manager.py, line ~1082, in ingest_document():
  After: documents = chunk_document(...)
  Before: vector_store.add_documents(documents)
  
  Code:
    from entity_consolidation import consolidate_dean_chunks
    documents = consolidate_dean_chunks(documents)

DETECTION CRITERIA:
- Chunk must contain lowercase "dean"
- Chunk must contain at least one person title: 
  ['dr.', 'engr.', 'arch.', 'prof.', 'mr.', 'ms.', 'mrs.']
- Chunk must NOT contain "dean's" (possessive)
- Chunk must NOT contain "office" in first 150 chars
- Chunk must NOT contain "is tasked" or "responsibilities" in first 200 chars

CONSOLIDATION ORDER:
Chunks sorted by min(page_numbers) to ensure:
1. Main structured lists appear first (e.g., page 12 "DEANS" section)
2. Later scattered references appear after
3. Deterministic, repeatable ordering
