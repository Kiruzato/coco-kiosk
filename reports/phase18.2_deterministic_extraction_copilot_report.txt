COMPONENT 1: Intent Detection
-------------------------------------------------------------------------------
Function: is_dean_enumeration_query(query: str) -> bool

Logic:
  - Triggers: "who are" | "list" | "show" | "all"
  - Entity: "dean" | "deans"
  - Returns True if both present

Examples:
  ✅ "who are the deans" → True
  ❌ "who is the dean of CASEd" → False

COMPONENT 2: Dean Extraction
-------------------------------------------------------------------------------
Function: extract_deans_from_text(text: str) -> List[Dict]

Pipeline:
  1. Split into lines
  2. Filter: skip empty/headers, require title (Dr.|Engr.|Arch.|Prof.)
  3. Parse: extract title, name (until delimiter), college
  4. Normalize: title casing, name casing
  5. Deduplicate: by lowercase name
  6. Return: in document order

Key Helpers:
  - _parse_dean_line(): Extract title/name/college from line
  - _normalize_title(): "DR." → "Dr."
  - _normalize_name_casing(): "ERIC A. MATRIANO" → "Eric A. Matriano"
  - _parse_college_info(): Extract/clean college name

Output:
  [{'full_name': 'Dr. Christine Gil O. Almazan',
    'title': 'Dr.',
    'college': 'CASEd',
    'raw_line': 'DR. CHRISTINE GIL O. ALMAZAN Dean, CASEd'}, ...]

COMPONENT 3: Output Formatter
-------------------------------------------------------------------------------
Function: format_dean_list(deans: List[Dict]) -> str

Output:
  The deans are:
  
  1. Dr. Christine Gil O. Almazan — Dean, CASEd
  2. Dr. Leilani E. Capili — Dean, College of Nursing
  ...

===============================================================================
BUGS FIXED
===============================================================================

BUG 1: All-Caps Titles Not Detected (4/6 extraction)
-------------------------------------------------------------------------------
ROOT CAUSE: Word boundary \b in regex fails on "DR." (all-caps)
FIX: Removed \b, added re.IGNORECASE
  # Before: r'\b(Dr\.|Engr\.)\s+'
  # After:  r'(Dr\.|Engr\.)', line, re.IGNORECASE

BUG 2: Names Truncated After Initials
-------------------------------------------------------------------------------
ROOT CAUSE: Regex stopped after initials ("Eric A. M")
FIX: Changed to delimiter-based extraction (not complex regex)
  # Find earliest delimiter: "(", "Dean", "—"
  # Extract: everything between title and delimiter

BUG 3: "&" Suffix Not Removed from College
-------------------------------------------------------------------------------
ROOT CAUSE: Regex required space before "&"
FIX: Made whitespace optional
  # Before: r'\s+&\s+Asst\..*$'
  # After:  r'\s*&\s*Asst\.?.*$'
