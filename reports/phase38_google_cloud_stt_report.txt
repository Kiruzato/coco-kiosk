================================================================================
OVERVIEW
================================================================================

Phase 38 adds Google Cloud Speech-to-Text V1 as an STT engine with backend-
authoritative usage tracking to monitor the 60-minute monthly free tier quota.

Key Features:
- Google Cloud STT using Standard model with data logging (free tier eligible)
- Backend-authoritative usage tracking (60-minute monthly quota)
- Usage rounded UP to next full second per Google billing rules
- Automatic monthly reset on the 1st of each month (lazy reset)
- Admin UI showing usage progress bar and credential status
- Hot reload support for credentials without server restart

================================================================================
FILES CREATED
================================================================================

1. voice/usage_tracker.py
   - STTUsageTracker class with monthly reset logic
   - UsageStats dataclass for structured usage data
   - Thread-safe file persistence with threading.Lock()
   - round_up_seconds() for Google billing compliance
   - Lazy reset: checks month on each usage update
   - Data stored in: data/stt_usage.json

2. voice/engines/google_cloud_stt.py
   - GoogleCloudSTTEngine class implementing STTEngine interface
   - Uses 'default' model with data logging for free tier
   - Credential validation via GOOGLE_APPLICATION_CREDENTIALS
   - Async transcribe() method returning TranscriptionResult
   - is_available() checks credentials and package availability

================================================================================
DESIGN DECISIONS
================================================================================

| Decision               | Choice                        | Rationale                    |
|------------------------|-------------------------------|------------------------------|
| Credentials storage    | Service account JSON in .env  | Standard Google pattern      |
| Usage tracking storage | Separate stt_usage.json       | Clear separation, easy reset |
| Monthly reset          | Lazy reset on first request   | No cron deps, RPi-friendly   |
| Billing granularity    | Round UP to next second       | Matches Google Cloud billing |
| Free tier model        | 'default' with data logging   | Required for free tier       |

================================================================================
SETUP INSTRUCTIONS
================================================================================

1. Create Google Cloud Project:
   https://console.cloud.google.com

2. Enable Speech-to-Text API:
   APIs & Services > Enable APIs > Speech-to-Text API

3. Create Service Account:
   IAM & Admin > Service Accounts > Create
   Grant: Cloud Speech-to-Text API User role

4. Download JSON Key:
   Service Account > Keys > Add Key > Create new key > JSON

5. Configure Environment:
   GOOGLE_APPLICATION_CREDENTIALS=/path/to/key.json

6. Install Dependencies:
   pip install google-cloud-speech>=2.21.0
