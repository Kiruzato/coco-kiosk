Phase 41: Text-Voice Response Synchronization Testing Instructions
==================================================================

Overview
--------
Phase 41 synchronizes text and voice output so they appear as a single
unified response event. Text no longer appears before audio is ready.

Changes Made
------------
1. Added helper functions: synthesizeTTSOnly(), fetchAudioBlob(), playAudioBlob()
2. Modified handleSubmit() - synthesizes TTS before displaying text
3. Modified processVoiceInput() - fetches audio before displaying text
4. Loading indicator stays visible until both text and audio are ready

==================================================================
TEST CASES
==================================================================

TEST 1: Typed Input with TTS Enabled
------------------------------------
Prerequisites:
- TTS is enabled (voice button visible and working)

Steps:
1. Type "Who are the deans?" in the text input
2. Press Enter or click Send

Expected Behavior:
- Loading indicator shows "Preparing response..."
- Loading indicator stays visible during TTS synthesis (~300-800ms)
- Text and audio appear/start simultaneously
- No visible gap between text appearing and audio starting

PASS: [ ]  Text and audio appear together
FAIL: [ ]  Text appears before audio starts


TEST 2: Voice Input
-------------------
Prerequisites:
- TTS is enabled
- Microphone access granted

Steps:
1. Click the microphone button
2. Say "What are the different colleges?"
3. Wait for processing

Expected Behavior:
- Loading indicator shows "Processing your voice..."
- Loading stays visible while audio is fetched
- Text and audio appear/start simultaneously

PASS: [ ]  Text and audio appear together
FAIL: [ ]  Text appears before audio starts


TEST 3: TTS Disabled - Typed Input
----------------------------------
Prerequisites:
- TTS is disabled (no voice configuration)

Steps:
1. Type "Where is the library?" in the text input
2. Press Enter or click Send

Expected Behavior:
- Loading indicator shows "Thinking..."
- Text appears immediately when response received
- No audio plays (TTS disabled)
- Behavior unchanged from before Phase 41

PASS: [ ]  Text appears immediately, no audio
FAIL: [ ]  Unexpected delay or behavior


TEST 4: TTS Disabled - Voice Input
----------------------------------
Prerequisites:
- TTS is disabled
- Microphone access granted

Steps:
1. Click the microphone button
2. Ask any question
3. Wait for processing

Expected Behavior:
- Transcription shown as user message
- Response text appears immediately
- No audio plays

PASS: [ ]  Text appears immediately, no audio
FAIL: [ ]  Unexpected delay or behavior


TEST 5: TTS Synthesis Failure
-----------------------------
Prerequisites:
- TTS enabled but configured to fail (e.g., network issue)

Steps:
1. Simulate TTS failure (disconnect network after chat response)
2. Type a question and submit

Expected Behavior:
- Loading shows "Preparing response..."
- After synthesis fails, text still appears
- No audio plays, no error message shown
- Graceful degradation

PASS: [ ]  Text appears despite TTS failure
FAIL: [ ]  Stuck in loading or error state


TEST 6: User Interruption During TTS Playback
---------------------------------------------
Prerequisites:
- TTS enabled and working

Steps:
1. Type a long question that generates a long response
2. Wait for text and audio to appear
3. While audio is playing, click the text input

Expected Behavior:
- Audio stops immediately when input is clicked
- User can start typing new question
- Phase 40 interruption behavior preserved

PASS: [ ]  Audio stops on user input
FAIL: [ ]  Audio continues playing


TEST 7: Rejected Answer (Low Confidence)
----------------------------------------
Prerequisites:
- TTS enabled

Steps:
1. Ask an out-of-scope question like "What's the weather?"

Expected Behavior:
- Text appears immediately (no TTS for rejected answers)
- No audio plays
- Response shows appropriate rejection message

PASS: [ ]  No TTS delay for rejected answers
FAIL: [ ]  Delayed or unexpected behavior


TEST 8: Rapid Sequential Questions
----------------------------------
Prerequisites:
- TTS enabled

Steps:
1. Type "Who are the deans?" and submit
2. Immediately after text appears, type another question
3. Submit before audio finishes

Expected Behavior:
- First audio is interrupted
- Second question processes normally
- Second text and audio appear together

PASS: [ ]  Sequential questions work correctly
FAIL: [ ]  Race conditions or stuck states


TEST 9: Loading Indicator Text
------------------------------
Prerequisites:

Steps:
1. Type a question and submit

Expected Behavior (Typed Input):
- Initially: "Thinking..." (during API call)

Expected Behavior (Voice Input):
- "Processing your voice..." (throughout)

PASS: [ ]  Loading text updates appropriately
FAIL: [ ]  Loading text incorrect or not updating
